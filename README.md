# Saje landing page

Landing page and waitlist for Saje, a study app for students that combines screen blocking, deadlines and social accountability in one place.

It is a single static page: `index.html` with inline CSS and JavaScript, the images in the repo root, and Lenis (loaded from a CDN) for smooth scrolling. It has scroll animations, a mobile layout and a waitlist form.

## Run it

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then go to http://localhost:8000.

The Saje app itself lives in a separate private repo.
